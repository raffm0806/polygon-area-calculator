# Polygon Area Calculator

An Object-Oriented Python application that uses inheritance to define `Rectangle` and `Square` classes, providing geometric calculations and visual representations. Built for the **freeCodeCamp Scientific Computing with Python** certification.

## 🛠️ Features

* **Class Inheritance:** `Square` inherits directly from `Rectangle` and automatically synchronizes side dimensions.
* **Geometric Calculations:** Calculates area, perimeter, diagonal length, and shape fitting (`get_amount_inside`).
* **Visual Representation:** `get_picture` prints an ASCII representation using `*` characters.
* **Custom Output:** Implements `__str__` methods for readable object string representations.

## 💻 Tech Stack

* **Language:** Python 3 (Object-Oriented Programming & Inheritance)
